Featured Project

📸 Active Learning Pipeline for Automated Image Annotation (AWS)

I built an end-to-end active learning system that automates annotation of in-cabin automotive images for Veoneer. The pipeline integrates ML-based auto-labeling, confidence-driven sampling, human-in-the-loop corrections, and continuous retraining to dramatically reduce labeling cost and accelerate dataset delivery for ADAS and in-cabin sensing workloads.

Architecture of the AWS-based active learning pipeline.

What I Built

  • Designed a scalable ML system using S3, Rekognition, YOLOv8 Pose, Lambda, Ground Truth, and SageMaker.
  • Implemented a confidence-based judgment engine to route low-quality predictions to human labeling.
  • Created CI/CD retraining pipelines using CodePipeline & CodeBuild.
  • Developed dual-model logic for visibility classification and pose annotation.
  • Delivered reusable AWS CDK stacks for computer vision annotation workloads.

Impact

  • Reduced annotation cost by 90–99%.
  • Cut dataset turnaround from weeks → hours.
  • Achieved mAP@50: 94.9% (head) and 98.4% (keypoints).
